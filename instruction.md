# Language Learning Chrome Extension

a chrome extension, that can help me to learn a new language. 
## v1 version

This extension will have the following features:

1. translate selected text in the web page to the target language. 
2. collect the words and phrases that I want to learn, and save them to the db.
3. you can translate all text in the web page to the target language
4. word book: you can review the words and phrases that you have collected, and you can also delete them.
5. word highlight: you can highlight the words that you want to learn in the web page.
6. double click the word to translate it to the target language.
7. user can set the target language in the popup page.
8. target language is default to 'zh-cn' and user can change it in the popup page.
9. except the word book, the extension will also have a sentence book, that the word cited in the sentence will be highlighted.
